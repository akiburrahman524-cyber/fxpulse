---
name: fxpulse-scan
description: Scan the forex majors against the London-session opening range and report breakouts. Use when the user asks what the FX market is doing this session, or for a morning/afternoon market read.
---

Run `python3 fx_scan.py` from the fxpulse directory and report the table as-is,
with the data-freshness line intact. Descriptive analysis only - never present
a breakout as a recommendation to trade.
